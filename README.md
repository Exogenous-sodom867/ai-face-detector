## 🧠 What is ai-face-detector?

ai-face-detector is a simple app that checks if a face is real or created by artificial intelligence. It uses a method called Deep Learning to spot images made by tools like GAN, Stable Diffusion, and Midjourney. The tool works well, with about 95% accuracy. It runs using a MobileNetV2 model and transfer learning techniques to improve detection. Behind the scenes, it uses a REST API built on FastAPI.

You do not need to understand complex terms or coding to use this app. It’s made to work on your Windows computer without extra setup.
